# Employee Hub

LocDoc company app — theme and layout from the Lab App Template.

## Develop

```bash
cp .env.example .env.local
npm install
npm run dev
```

Local login: **admin** / **admin** (with `LAB_DEV_SIMPLE_AUTH=1` in `.env.local`).

Standards: [`docs/LAB_STANDARDS.md`](docs/LAB_STANDARDS.md) · [`docs/NAMING.md`](docs/NAMING.md) · [`AGENTS.md`](AGENTS.md)

Optional: hand those docs to an LLM when building features.
